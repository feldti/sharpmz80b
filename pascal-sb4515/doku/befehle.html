Befehlsreferenz

Editorkommandos, Tokenformat, alle Schlüsselwörter mit Prüf- und Ausführungsroutine, Datentypen, Gleitkommaformat und Fehlernummern. Erzeugt von tools/mkref4515.py (make ref); die gleiche Seite steht in docs/BEFEHLE_SB4515.md. Die Kurzbeschreibungen folgen dem Handbuch.

Speicheraufteilung

Bereich Inhalt
0000h–129Fh Monitor SB-1511 (Quelle SB1511.asm); GOOUT springt beim Laden nach PAS_BOOT
12A0h–12FCh FFh-Füllung
12FDh–614Ah Interpreter: Editor, Tokenizer, Prüflauf, Ausführung, Gleitkomma, Ein-/Ausgabe
ab 614Bh Programmtext (TXT_START … TXT_END); beim Laden stehen hier noch FKEY_DEF und PAS_INIT
unter STACK_TOP Stapel, WORKBUF (−320h), INBUF (−56h), Textgrenze TXT_LIMIT (−C8h); darunter globale Variablen, Symboltabellen und Laufzeitstapel

Start: PAS_INIT belegt die Funktionstasten, macht GOOUT unschädlich und springt nach PAS_START (Speichertest, Kopfmeldung, PAS_READY).

Editorkommandos

Eingabe im Kommandomodus (CMD_LOOP). Ein Buchstabe wählt über CMD_TAB das Kommando; nicht belegte Buchstaben ergeben Err 40. Programmzeilen haben keine gespeicherte Nummer – die Nummer ist die Position im Text.

Eingabe Routine Adresse Wirkung
A PCMD_A 1516h Append: Datei vom Band suchen (Typ A0h, Name passend) und hinter das Programm im Speicher laden.
B PCMD_B 1639h Eingabe ab Zeile 0 (vor dem vorhandenen Programm).
D PCMD_D 173Fh Zeilen löschen.
E PCMD_E 17C2h Obergrenze des Speichers setzen (STACK_TOP); muss über TXT_END + 438h und unter dem RAM-Ende liegen.
F PCMD_F 360Ch Belegung der Funktionstasten anzeigen.
G PCMD_G 3B80h Programm ausführen. Erst Prüflauf über den ganzen Text (Deklarationen, Syntax, Typen), Symboltabellen anlegen; beim "." nach dem Hauptblock weiter zur Ausführung (RUN_START).
H PCMD_H 161Fh Listing auf den Drucker (sonst wie P).
I PCMD_I 1610h IPL: PPI Port C Bit 3 zurücksetzen und HALT (Neustart über den IPL).
K PCMD_K 188Bh Programm löschen (wie NEW).
L PCMD_L 1718h Zeiger n Zeilen zurück, Zeile anzeigen.
M PCMD_M 16C5h freien Speicher anzeigen ("nnnnn Bytes").
N PCMD_N 16FEh Zeiger n Zeilen vorwärts, Zeile anzeigen.
P PCMD_P 1760h Listing auf den Bildschirm. Leertaste hält an, BREAK bricht ab.
Q PCMD_Q 1618h zurück in den Monitor.
R PCMD_R 35A1h Systemkommandos: RC40/RC80, RN (normal), RR (invers), RS a,e (Rollbereich).
S PCMD_S 1569h Save: Programmtext als Datei vom Typ A0h auf Band schreiben.
T PCMD_T 16FBh (nicht im Handbuch) Zeiger auf den Anfang, dann wie N.
V PCMD_V 1514h Verify: Kassettendatei mit dem Programm im Speicher vergleichen. Teilt sich den Code mit PCMD_A (A = 0: Vergleich, A = 1: Anhängen).
Z PCMD_Z 162Ah Eingabe am Programmende fortsetzen.
# CMD_LOOP 1374h Zeilennummern im Listing ein/aus
$ CMD_LOOP 1374h Einrücken bei der Eingabe ein/aus
n … PCMD_LINENO 1403h Zeile beginnt mit einer Nummer n: "n" allein löscht Zeile n, "n Text" ersetzt Zeile n, "n" mit Pfeil (1Fh) setzt die Eingabe ab Zeile n fort.
Pfeil (1Fh) PCMD_ARROW 169Dh Pfeil (1Fh) am Zeilenanfang: CR allein -> Eingabe ab Zeiger, sonst Zeile am Zeiger einfügen.

Programmtext und Token

Jede Zeile: Anzahl der Einrückungs-Leerzeichen, Token und Zeichen, 0Dh. Schlüsselwörter werden zu Token 60h–E1h (KWTAB, letztes Zeichen mit Bit 7). Bezeichner bleiben als Text stehen (groß geschrieben); der Prüflauf trägt davor ein Token E2h (global) bzw. E3h (lokal) samt Adresse ein und hinter THEN/ELSE/DO das Sprungziel. Im Listing erscheinen Schlüsselwörter klein.

Token ab D8h tragen Operandenbytes; ihre Anzahl steht in TOKLEN_TAB:

Token Bedeutung Operandenbytes
D8h PROCEDURE 3
D9h FUNCTION 4
DAh THEN (Sprungziel) 2
DBh ELSE (Sprungziel) 2
DCh DO (Sprungziel) 2
DDh : 2
DEh Kommentar {…} (Verweis auf das Ende) 2
DFh Zeichen/Text '…' 3
E0h Text "…" (Verweis auf das Ende) 2
E1h ARRAY 6
E2h globaler Bezeichner (Typ, Abstand zu INBUF) 3
E3h lokaler Bezeichner (Typ, Abstand) 3
E4h Prozeduraufruf 3
E5h Funktionsaufruf 3
E6h Zahlkonstante (Typ + 5 Bytes) 6

Datentypen und Laufzeitstapel

Code Typ Größe samt Typbyte
0 REAL 6
1 INTEGER 3
2 CHAR 2
3 BOOLEAN 2

Der Laufzeitstapel (RT_SP) wächst nach unten; jeder Eintrag beginnt mit dem Typbyte. Felder sind durch Bit 6 im Typ gekennzeichnet.

Gleitkommaformat

5 Bytes: Byte 0 = Vorzeichen in Bit 7 (1 = positiv) und Exponent mit Bias 40h, Bytes 1–4 = Mantisse, niederwertiges Byte zuerst, normalisiert (Bit 31 gesetzt). Wert = Mantisse / 2^32 · 2^(Exponent − 40h); Null hat die Mantisse 0. Bereich laut Handbuch bis ±0.92233720E+19 (größer: Err 13). WRITELN zeigt 8 gültige Ziffern; ARCTAN ist nur auf etwa 5 Stellen genau (Test tools/test_sb4515_run.py).

Routine Adresse Wirkung
FADD 4806h (DE) = (DE) + (HL), Gleitkomma. Exponentenausgleich, Addition bzw. Subtraktion der Mantissen, Normalisieren; Überlauf -> ERR_13, Unterlauf -> 0.
FSUB 4803h (DE) = (DE) - (HL), Gleitkomma (Vorzeichen von (HL) umgedreht, dann wie FADD).
FMUL 4900h (DE) = (DE) * (HL). Überlauf (Betrag ab etwa 0.92233720E+19, Handbuch) -> ERR_13.
FDIV 49CEh (DE) = (DE) / (HL); Division durch 0 bzw. Überlauf -> ERR_13.
FCMP 4E5Eh (DE) mit (HL) vergleichen: Z = gleich, C = (DE) < (HL).
FINT 4E81h (DE) auf die ganze Zahl abschneiden (vermutlich, wie TRUNC).
STR2FP 4A6Dh Zahl im Text ab HL in Gleitkomma nach (DE) wandeln.
FP2STR 4CB6h Gleitkommazahl (HL) in Text wandeln (Puffer ab 4CA0h).
FSIN 5011h Sinus (DE) über die Reihe in x/(pi/2) (Koeffizienten ab 50E2h).
FCOS 5100h Kosinus über FSIN (Argument um pi/2 verschoben, Vorzeichen angepasst).
FTAN 510Fh Tangens = sin(x) / cos(x).
FATN 546Fh Arcustangens (DE) (Reihe ab 551Ah). Nur auf etwa 5 Stellen genau: ARCTAN(1) ergibt 0.78540579 statt 0.78539816 (test_sb4515_run.py).
FSQRT 513Ah Quadratwurzel (DE).
FEXP 51FDh e hoch (DE) (Reihe ab 52FEh, ln 2 = 5326h).
FLN 532Eh Natürlicher Logarithmus (DE) (Konstanten ab 543Ah: sqrt(2), ln(2)/2 ...).
FLOG 545Dh Zehnerlogarithmus: LN(x) * log10(e) (5468h).
FRND 4F93h RND: neue Zufallszahl aus der vorigen (Startwert 4F8Eh, Faktor 23).
