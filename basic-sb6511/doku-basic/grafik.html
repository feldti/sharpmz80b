Grafik, Bildschirm und Drucker

Grafik

Das BASIC unterstützt zwei Grafikebenen mit je 320 × 200 Pixeln, 1 Bit je Pixel. Das Grafik-VRAM liegt bei E000h–FFFFh und wird nur für den Zugriff über die PIO (Port E8h, Bit 7) in den Adressraum eingeblendet. Port F4h (GRPH) wählt die Ebene zum Lesen und die Ebenen zum Schreiben.

Adressierung

GR_ADDR berechnet zu einem Punkt (x, y):

Adresse = E000h + y · 40 + x / 8        Bit = x mod 8

Eine Zeile hat also 40 Bytes; Bit 0 eines Bytes gehört zum kleinsten x.

Befehle

Befehl Wirkung
GRAPH [I n] [O ab] [C] [F] Leseebene n (1–2), Schreibebenen als Ziffernfolge (0–2), gewählte Ebenen löschen (C) oder füllen (F); schreibt den Wert nach Port F4h (GRPH_PORT = GRPH_IN + GRPH_OUT)
SET x,y / RESET x,y Pixel setzen bzw. löschen; Grafikposition dorthin. Außerhalb des Bildes passiert nichts
LINE x1,y1,x2,y2[,x3,y3 …] Streckenzug zeichnen (mindestens zwei Punkte, sonst Fehler 1)
BLINE … Streckenzug löschen
POSITION x,y Grafikposition setzen (x 0–319, y 0–199, sonst Fehler 3)
PATTERN [-]n, m$[, …] Bitmuster an der Grafikposition zeichnen, n = 1–24 Zeilen je Spalte; mit - in Gegenrichtung
POINT(x,y) Pixelzustand: Bit 1 = Ebene 1, Bit 0 = Ebene 0 (Wert 0–3)
POSH, POSV aktuelle Grafikposition x bzw. y

Pixelroutinen

Alle Pixelbefehle laufen über GR_PIXOP (DE = x, HL = y). A enthält das zweite Byte eines Z80-Bitbefehls – C6h für SET 0,(HL), 86h für RES 0,(HL), 46h für BIT 0,(HL). Die Routine addiert die Bitnummer (· 8) und setzt den fertigen Befehl in GR_PIX_DO ein. So erledigt ein einziges Stück Code Setzen, Löschen und Testen.

Routine Aufgabe
GR_SETPIX, GR_RESPIX, GR_TESTPIX Pixel bei (DE, HL)
GR_SETCUR, GR_RESCUR Pixel an der Grafikposition GR_X/GR_Y
GR_POINT (569Dh) beide Ebenen testen, A = 0–3 bzw. FFh außerhalb
GR_LINE (573Ah) Linie nach Bresenham von (GRL_X1, GRL_Y1) nach (DE, HL)
LINE_SET, LINE_RESET Streckenzug aus einer Punktliste (DE, je Punkt x und y als 16-Bit-Werte), A = Anzahl Strecken
GR_FILL, GR_CLEAR gewählte Ebenen mit FFh füllen bzw. löschen
PAT_DRAW (58A2h) Bitmuster zeichnen
GR_WRBYTE ein Byte mit Maske ändern (Adressen über FFFFh werden übergangen)

GR_LINE verschiebt alle Koordinaten intern um 4000h (GR_BIAS), damit Differenzen positiv bleiben, und setzt die Schrittrichtung als INC/DEC-Befehle in den Code ein (GRL_INCX/GRL_INCY). Punkte außerhalb von 320×200 werden nicht gezeichnet.

PATTERN

PATTERN n, m$ zeichnet jedes Zeichen von m$ als 8 waagerechte Pixel. Nach n Zeichen (untereinander) geht es eine Spalte (8 Pixel) weiter nach rechts. Mit negativem n läuft die Zeichnung nach oben statt nach unten; dafür werden Schrittweite und ADD/SBC in PAT_STRIDE/PAT_STEP eingesetzt.

Textbildschirm

Der Textbildschirm (Text-VRAM bei D000h) hat 25 Zeilen zu 40 oder 80 Zeichen. Ausgabe, Cursor und Editor gehören zum Monitor; das BASIC steuert sie über einige Befehle:

Befehl Wirkung
CONSOLE [S a,b] [C 40|80] [R|N] Rollbereich Zeile a bis b (1–24, sonst Fehler 3), 40/80 Zeichen je Zeile, inverse (R) bzw. normale (N) Darstellung über PPI-Port A Bit 4. Mehrere Angaben nacheinander möglich
CURSOR x,y Cursor setzen; x kleiner als die Zeilenbreite, y 0–24, sonst Fehler 3
CSRH, CSRV Cursorspalte bzw. -zeile
CHARACTER$(x,y) Zeichen an einer Bildschirmposition als String
CHANGE Groß-/Kleinschreibung der Buchstabentasten tauschen
DEF KEY(n)=text, KLIST Funktionstasten 1–10 belegen/anzeigen

Steuerzeichen in Strings (z. B. Cursorbewegungen, Bildschirm löschen) wertet die Zeichenausgabe des Monitors aus.

Drucker

Der Drucker hängt an den Ports FEh (Steuerung/Status) und FFh (Daten).

Routine Aufgabe
PRN_OUT Byte an Port FFh, Strobe über FEh, auf den Drucker warten (PRN_WAIT; Zeitüberschreitung: Fehler 65)
PRN_ESC ESC (1Bh) senden
PRN_CHECK Status abfragen (ESC 03h, ESC 04h); Fehler 67 bzw. 66
PRN_TEXT Text drucken, Spalte PRN_COL mitzählen; Steuerzeichen 05h, 06h, 10h–15h werden in Druckerbefehle übersetzt (PRN_CTRL), andere unter 20h übergangen
PRN_LINE Text unverändert drucken (für LIST/P, DIR/P)
PRN_CRLF, PRN_EOLCHK Zeilenvorschub (bedingt)
PRN_TABZONE Komma in PRINT: Leerzeichen bis zur nächsten durch 10 teilbaren Spalte
Befehl Wirkung
PRINT/P …, LIST/P, DIR/P Ausgabe auf den Drucker
PAGE/P n Seitenlänge n (1–255) einstellen (ESC 12h n)
IMAGE/P a$[;…] Texte als Bitmuster senden (ESC 18h, Länge, Daten; höchstens 1000 Bytes, sonst Fehler 3); ohne Argument Zeilenvorschub
COPY/P n Hardcopy: 1 = Textbildschirm (25 Zeilen ab D000h), 2–4 = Grafik (Ebenen je nach n, invertiert je nach Darstellung)

Für COPY/P liest GRAM_READ2 ein Byte aus beiden Grafikebenen; je nach Art der Kopie werden dazu andere Befehle in GR2_PATCH eingesetzt. BREAK bricht die Hardcopy ab.

Die Druckerbefehle (ESC-Folgen) entsprechen Sharps Druckern der Zeit; welche Modelle genau gemeint sind, ist aus dem Code nicht ersichtlich.
