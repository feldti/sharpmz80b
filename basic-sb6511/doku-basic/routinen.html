6600h SIO_VECTORS Dieser Block ist die "besondere Anpassung" für die serielle Schnittstelle. Er steht hinter dem GP-IB-Teil in einem Bereich, der vorher eine Kopie von 560Bh-56A9h enthielt (siehe OLD_COPY bei 6561h), und wird über drei neue Schlüsselwörter (Token 80h,E0h-E2h) angesprochen: RSMODE {A|B} [,R n] [,T n] [,M n] [,RX n] A/B Kanal wählen (A = Ports B0h/B1h, B = Ports B2h/B3h) R n Empfangs-Datenbits 5..8 (SIO WR3 Bit 7-6) T n Sende-Datenbits 5..8 (SIO WR5 Bit 6-5) M n Byte für SIO WR4 direkt (Taktteiler, Stoppbits, Parität) RX n n<>0: Empfänger ein, Ringpuffer leeren, Interrupts ein; n=0: Empfänger aus.
