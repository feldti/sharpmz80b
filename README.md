# sharpmz80b

Commented disassemblies, documentation and tools for the **Sharp MZ-80B** (Z80-based personal
computer, 1981).

All assembler sources reassemble with [pasmo](https://pasmo.speccy.org/) into
**byte-identical** images of the original software. Source comments and the HTML
documentation are written in **German**.

## Contents

| Directory | Contents |
|-----------|----------|
| [`ipl/`](ipl/) | **IPL ROM** (Initial Program Loader, 2 KB at 0000h–07FFh). Boots the system from cassette, floppy disk (MB8876 FDC) or an external memory card, then triggers the "Normal Start" into RAM. |
| [`monitor-sb1511/`](monitor-sb1511/) | **Monitor SB-1511** (also used by SB-1521), taken from the FDOS SB-7010 disk. Commands J, M, D, L, S, V; cassette, screen, keyboard and music routines. Original Sharp label names from `MONEQU` are kept. |
| [`basic-sb6511/`](basic-sb6511/) | **Disk BASIC SB-6511** including monitor SB-1510, variant with the RS-232C extension (`RSMODE`, `RSO`, `RSI`) and GP-IB (IEEE-488) support. The BASIC part (from 1222h) is relocatable. HTML documentation in [`doku-basic/`](basic-sb6511/doku-basic/index.html). |
| [`basic-sb6610/`](basic-sb6610/) | **Double Precision Disk BASIC SB-6610**, a descendant of SB-6511 using 9-byte BCD numbers with 16 decimal digits, plus `PRINT USING` and `DELETE`. HTML documentation in [`doku/`](basic-sb6610/doku/index.html) (Markdown sources in `doku/src/`). |
| [`mz80bfont/`](mz80bfont/) | **MZ-80B character set as fonts** (TTF, BDF, PCF, PSF), generated from the original 8×8 character generator ROM, plus a terminal launcher for talking to a real MZ-80B over a serial line with `minicom`. See [`mz80bfont/INSTALL.md`](mz80bfont/INSTALL.md). |

Each `.asm` file comes with a `.lst` listing showing addresses and generated bytes next to the
source.

## Assembling

```sh
pasmo --bin ipl/mz80b_ipl.asm            ipl.bin
pasmo --bin monitor-sb1511/SB1511.asm    sb1511.bin
pasmo --bin basic-sb6511/SB6511_RS232.asm sb6511.bin
pasmo --bin basic-sb6610/sb6610.asm      sb6610.bin
```

Expected sizes: IPL 2048 bytes (0800h), SB-1511 4768 bytes (12A0h), SB-6511 and SB-6610
32256 bytes each (7E00h). The `.lst` listings were made with a separate tool that is not
part of this repository.

The BASIC images (7E00h bytes) correspond to the content of the `.mzf` files without their
128-byte MZF header. The IPL loads them to 8000h and they run from 0000h after the Normal Start.

## Fonts

The ready-made fonts are included. The `MZ80B Raw` variant maps every byte 0x20–0xFF to its ROM
glyph when used with `minicom -R CP437`; the `MZ80B` variant uses meaningful Unicode code
points (♠♥♦♣, arrows, box drawing, ¥, £, π …). Both variants additionally contain all 256 ROM
glyphs at U+E000 + code.

```sh
mkdir -p ~/.local/share/fonts ~/.local/share/konsole
cp mz80bfont/MZ80BRaw.ttf mz80bfont/MZ80B.ttf ~/.local/share/fonts/ && fc-cache -f
cp mz80bfont/MZ80B.profile ~/.local/share/konsole/
mz80bfont/mzterm.sh /dev/ttyUSB0 9600          # konsole (default), xterm, kitty or alacritty
```

To rebuild the fonts from a character ROM dump (requires Python 3 and `fontTools`):

```sh
python3 mz80bfont/build.py MZFONT.rom outdir        # MZ80B
python3 mz80bfont/build.py MZFONT.rom outdir raw    # MZ80B Raw
```

## Not included

The original ROM and disk images (`IPL.rom`, `MZFONT.rom`, `.mzf`, `.dsk` files) and the
manuals are not part of this repository. Some documentation pages mention a build and test
setup (`Makefile`, `tools/`) that is not included here either.

## Sources and references

- Hardware details partly based on the MAME driver `sharp/mz2000.cpp`; uncertain points are
  marked as such in the comments.
- Sharp's original symbol names come from the files on the original disks (e.g. `MONEQU.ASC`).
